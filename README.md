# Anime Haul: Alpine Run

一个面向 Android 的 Godot 4 卡车驾驶原型：动漫风格场景与卡车 + 写实感柴油机/气刹音效。当前版本采用轻量 2D 伪透视表现，优先保证移动端可运行和驾驶循环清晰。

## 开始运行

1. 安装 Godot 4.x。
2. 在 Godot Project Manager 中导入 `project.godot`。
3. 打开项目并运行主场景。
4. Android 导出：在 Project > Export 中添加 Android preset，设置包名后导出 APK；本项目不依赖外部网络服务。

## 游戏循环

接取货运合同，在高山公路上加速、刹车和变道，避开交通，消耗燃油；到达目标距离后获得报酬并自动接取下一条路线。支持键盘和屏幕触控按钮。

## 声音设计

`audio/engine_loop.wav` 是由低频柴油脉冲、机械谐波与引擎轰鸣叠加形成的循环；`audio/air_brake.wav` 是带攻击/衰减包络的气刹嘶声。它们不使用卡通音效，和动漫画面形成“视觉动漫、听觉写实”的对比。

## 已知范围

这是一个完整可玩的原型，不是完整 3D 物流模拟器。后续可以扩展真正 3D 车辆物理、车库升级、天气、存档、更多路线和 Android 陀螺仪转向。
