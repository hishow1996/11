# Anime Haul: Alpine Run — 3D Android Prototype

这是一个面向 Android 的 Godot 4 3D 卡车驾驶原型。视觉采用统一的动漫低多边形 3D 风格：赛璐璐色块、温暖色盘、深色轮廓感，以及高山公路、雪山、森林、交通车辆和第三人称跟随镜头。听觉保持写实感，使用本地柴油机循环与气刹音效。

## 开始运行

使用 Godot 4.x 导入 `project.godot`，然后直接运行主场景。主场景已经切换到 `scripts/main_3d.gd`，不再使用旧版 2D 原型脚本。

## Android 控制

当前版本使用更接近真实驾驶的模拟控制：左下角是可拖拽的虚拟方向盘，手指向左/右拖动对应转向，松手后会自动回中；方向盘带 8% 死区和非线性响应，能够减少手指抖动并提高直线行驶精度。右下角是独立的油门和刹车踏板，支持按住、多点触控和上下拖动调整力度，油门与刹车不会互相抢占触点。右上角为暂停。开发测试时仍支持 W/↑ 加速、S/↓ 刹车、A/← 左转、D/→ 右转。

控制脚本位于 `scripts/virtual_controls.gd`，通过 `steering_changed`、`throttle_changed` 和 `brake_changed` 三个信号连接到 3D 卡车。若要适配不同手机比例，优先调整 `_throttle_rect()`、`_brake_rect()` 和 `wheel_center` 的安全边距。

## 多场景道路

驾驶卡车会沿连续 3D 公路前进，依次经过开阔平原、山区雪岭、深山老林、乡村田园和动漫城市。平原包含麦田，山区包含岩壁与雪顶，森林包含密集树木，乡村包含农舍、作物行和粮仓，城市包含彩色建筑、屋顶和玻璃窗。HUD 会显示当前场景名称。控制变道并避开交通车辆后，路线距离、速度、燃油、损伤和收入都会实时更新；抵达目标距离后会完成货运合同并获得 €640，然后自动生成下一条路线。

## 导出 Android

在 Godot 中打开 Project > Export，添加 Android preset，设置包名和签名后导出 APK。建议在真实设备上测试触控按钮尺寸、横屏安全区域和音量。当前项目使用轻量 MeshInstance3D、DirectionalLight3D 与 Compatibility 渲染器，适合先做中低端安卓设备原型。

## 音频

`audio/engine_loop.wav` 是低频柴油脉冲与机械谐波叠加的循环；`audio/air_brake.wav` 是具有攻击/衰减包络的气刹嘶声。它们保留写实听感，与动漫画面形成对比。

雨雪声音系统已经接入 3D 驾驶逻辑。深山老林和城市部分路线会混入雨声、风声、水湿路面轮胎声与低频雷声；山区雪岭会切换为风声和压雪胎噪。雨雪音量会根据天气强度与车速自动变化，轮胎声只在对应天气下出现，所有环境声均使用本地循环 WAV，适合后续再替换为录音素材。

动态天气和昼夜交替也已经接入。游戏时间每 420 秒循环一天，HUD 显示当前时间和天气；太阳会随时间旋转并改变亮度、颜色和阴影，月光会在夜间启用，天空会经过清晨、白天、黄昏和夜晚色彩。城市、森林、雪山、乡村和平原使用不同雾密度；深山会更浓，雪山会带冷色雾。雨和雪通过 GPUParticles3D 显示，暴雨会触发闪电闪光，并与之前的雨声、雷声系统同步。

第二轮视觉升级加入了程序化渐变天空、动态湿路面与雪道路面材质，以及城市夜间 OmniLight3D 街灯。雨天道路会变暗并增加金属湿润感，雪天道路会变成冷色粗糙材质；城市建筑窗口和街灯在夜间提供暖色发光层。所有效果仍使用轻量程序化 Mesh 和 Compatibility 渲染器，便于后续制作安卓画质档位。

第三轮升级加入车辆动态反馈：车轮会根据车速滚动，车身会产生轻微路面起伏，车速越高第三人称镜头 FOV 会略微扩大，夜间卡车前灯会自动开启。道路上加入轻量水坑 Mesh，雨天显示并提高湿润反射，晴天和雪天隐藏，避免额外的安卓渲染负担。

第四轮升级为每类场景增加专属地标：城市有高塔和街区地标，乡村有风车与农田，深山森林有巨石和倒木，雪山有隧道入口与隧道灯，平原有湖泊和风力发电机。第三人称相机远景限制为 155 米，并结合雾效淡出远处几何体，降低安卓设备的绘制负担。

第五轮升级加入更像长途路线的道路事件：城市有十字路口、斑马线和交通灯，乡村有支路和路口标志，山区有弯道警示牌，平原加入跨水桥梁。交通碰撞后会触发短暂的镜头震动和速度反馈，让驾驶行为更有重量感。

第六轮升级丰富了交通流：道路上会出现小汽车、厢式车和公交车三种不同尺寸、速度和轮廓，车辆使用不同的车道节奏，前灯和尾灯会随昼夜改变发光强度。这样在城市、乡村和山区驾驶时，会有更接近长途运输路线的动态交通层次。

第七轮升级加入了移动端导航 HUD。左上角显示简化路线小地图、当前场景、目的地、剩余距离和路线进度条；城市、乡村、森林、雪山和平原使用不同场景色标，帮助玩家在长路线中快速理解自己所在的环境。

第八轮升级加入安卓“视角”按钮，可以在第三人称追尾视角和驾驶舱视角之间切换。第三人称视角突出卡车外观与场景，驾驶舱视角更适合沉浸式驾驶；两种模式都会保留速度感 FOV、碰撞震动、虚拟方向盘、油门和刹车控制。

第九轮升级加入补给玩法。城市和乡村路线各有一个动漫风格加油站，包含遮雨棚、油泵、发光提示灯和高柱标识；卡车靠近加油站并将速度降到低速后，会自动补充燃油并显示停车加油提示，适合后续扩展付费加油、维修和休息站系统。

第十轮升级加入“车库”按钮和四类卡车成长：发动机提高最高速度，轮胎提高转向抓地和刹车表现，油箱提高最大燃油容量，装甲降低碰撞损伤。升级使用货运收入购买，面板会显示当前等级和余额，所有效果直接作用于驾驶循环。

第十一轮升级加入 Android 本地存档。游戏每 10 秒自动写入 `user://anime_haul_save.json`，完成送货、购买升级和关闭窗口时也会保存；重新进入后会恢复金钱、燃油、损伤、合同进度、游戏时间以及四类升级等级，不需要联网或账号系统。

## 当前范围

这是一个可玩的 3D 原型，不是完整的商业级欧洲卡车模拟器。后续可以继续加入真实 3D 卡车模型、悬挂物理、车库升级、天气系统、存档、多城市地图、导航和陀螺仪转向。

第十二轮升级加入“设置”面板。玩家可以切换低、中、高画质，画质会调整雨雪粒子密度和远景距离；还可以调整方向盘灵敏度与主音量。设置参数和游戏进度一起保存到本地，方便适配不同性能的安卓设备。

第十三轮升级加入 Android 触觉反馈：交通碰撞使用较强短震，升级购买使用轻震，进入加油状态使用提示震，完成送货使用较长确认震；所有触觉都通过 `OS.has_feature("mobile")` 保护，桌面测试不会报错，HUD toast 仍会同步显示事件信息。

第十四轮升级加入车辆动态灯光和排气：发动机油门越大，排气烟雾粒子越明显；刹车时尾部刹车灯增强，变道时后部转向灯闪烁。排气粒子数量控制在较低范围，保持 Android Compatibility 渲染器下的移动端性能。

第十五轮升级加入山区维修站。卡车靠近维修站并减速停车后，会按时间逐步恢复碰撞损伤，同时按修复量扣除维修费；余额不足时会显示提示。维修站使用低面数车库、遮棚和扳手标识，与加油站一起组成长途路线服务设施。

第十六轮升级重构为大型 3D 分区路线。道路设计规模扩展到约 20000 公里，按照 1 公里区段进行流式生成；每个区段使用独立随机种子，分别生成城市建筑、乡村农田、森林树群、山区岩石或平原地标，并随机改变道路标线、建筑尺寸、树木比例和景物位置。车辆前进时生成前方区段、回收后方区段，避免整条路线同时占用内存，也避免连续景观机械重复。

第十七轮升级为五类大型区段加入独立的 3D 路线事件：城市立交、乡村木桥与溪流、森林湖泊与码头、雪山隧道入口、平原太阳能场。它们不是 2D 背景，而是由 3D Mesh、3D 位置和分区种子生成的可见路线记忆点。

道路本身也不再是单一直线：每个区段会生成独立的道路中心线、缓弯或连续弯、不同道路宽度、城市宽路、山区窄路和不同车道标线；卡车会根据 3D 道路中心线自动修正行驶方向，保证车辆真正沿着程序化道路前进。

第十八轮升级加入长途路线节点：每个流式区段会生成 3D 公里标，每 4 个区段配置一个带停车位和服务建筑的长途休息区。宏观地理带现在以 50 公里为单位切换，20,000 公里路线通过区段编号、随机种子和道路结构变化维持长期旅途的差异性。

第十九轮升级加入 3D 高程系统。道路不再是平面：平原使用缓起伏，乡村使用柔和坡度，高山雪谷使用更明显的上下坡和连续高程变化；每个道路段根据前后高度计算俯仰角，卡车会自动跟随道路高度并产生真实的上坡、下坡和山路行驶感觉。

城市宏观区域也单独加入了 3D 城市道路规则：道路两侧会生成连续人行道、成组街灯、发光灯具和随机斑马线节点，并与城市宽路、建筑群、十字路口和立交组合。城市不再只是路边几栋建筑，而是具有道路边缘、步行空间和夜间照明层次的完整 3D 街区。

第二十轮升级为其他宏观区域加入独立道路设施：乡村使用草肩和木栅栏，森林使用连续护栏与绿色反光标，雪山使用宽雪肩和高位雪杆，平原使用高速路中心线与震荡带。这样五类区域不仅风景不同，路面宽度、路肩材质、护栏和安全设施也不同。

第二十一轮升级加入 3D 路网分叉：城市区段周期性生成匝道，乡村区段生成带路牌的农场支路，雪山区段生成观景分叉路。每条分支拥有独立 Mesh 路面、道路边缘和指示牌，主路与支路形成可视化长途路网结构。

第二十二轮升级加入分支导航：小地图会同时显示主路线和黄色分支线，HUD 会根据当前宏观区域提示环城匝道、农场支路、森林湖区、雪山观景路或平原服务区，并显示对应英文目的地名，方便在超长路线中理解路网结构。

第二十三轮升级把每个 50 公里城市宏观带继续细分为市中心、住宅区、工业区和城市外环。市中心使用高层建筑和密集路灯，住宅区使用中低层楼群与斑马线，工业区使用大型厂房和中央隔离带，外环使用低层建筑与稀疏照明；HUD 会同步显示当前城市分区。

第二十四轮升级把乡村宏观带细分为农田、村庄、河谷和果园。农田强调作物行与开阔路肩，村庄使用住宅和木栅栏，河谷使用溪流与谷仓，果园使用成排果树；HUD 会显示当前乡村子区域，路侧植被和道路细节也会随分区切换。

第二十五轮升级把森林宏观带细分为针叶林、雨林、湖畔林和峡谷林。针叶林提高树木高度和密度，雨林增加苔藓与湿润道路，湖畔林加入水体边缘，峡谷林加入岩石和中央分隔设施；HUD 会显示当前森林子区域，护栏、反光标和雾中道路表现也随分区变化。

第二十六轮升级把高山雪谷细分为冰川山口、雪松山林、矿区山路和隧道群。冰川区加入冰面与雪肩，雪松区加入高山树群，矿区加入岩壁和警示条，隧道区加入连续隧道接近段；HUD 会显示当前雪山子区域，道路护栏、雪杆和坡度设施同步变化。

第二十七轮升级把平原宏观带细分为麦田高速、湖岸湿地、风电走廊和太阳能产业区。麦田区强调高速道路和作物地块，湿地区加入路侧水体，风电区加入风机与围栏，太阳能区加入成片光伏板与产业边缘设施；HUD 会显示当前平原子区域。

第二十八轮升级加入坡度动力反馈。卡车根据道路前方高程计算当前坡度，上坡会增加发动机负载并降低目标速度，下坡会产生滑行速度；车辆俯仰跟随道路坡面，柴油机音量与音高随速度和负载变化，HUD 会显示实时坡度百分比。

第二十九轮升级让交通车辆真正跟随程序化道路：小汽车、厢式车和公交车会根据道路中心线调整车道位置，沿弯道旋转，并同步道路高程改变高度与俯仰，不再沿固定直线平移。

第三十轮升级加入城市信号系统。流式城市路口会生成红绿灯并按周期切换，交通车辆在红灯前自动降低速度，绿灯后恢复通行；信号节点随城市区段流式生成与回收，夜间灯光和城市道路氛围保持一致。

第三十一轮升级开始按图片级动漫 3D 目标校准美术。项目加入城市、雪山和乡村视觉基准图，并提升卡车近景模型：增加前脸格栅、驾驶室侧窗、车身描边、挂车面板分缝、侧面装饰、保险杠灯组和更明确的赛璐璐材质响应；道路材质同步降低粗糙度并增加轻微金属反射，使移动端画面更接近统一的动漫 3D 视觉方向。资产记录见 `ASSETS.md`。

第三十二轮升级继续强化场景轮廓：山体改为尖顶和积雪分层结构，森林树木改为三层锥形树冠，城市建筑加入连续阳台与栏杆细节；环境启用克制的移动端辉光，让车灯、城市灯、隧道灯和雨夜反射更接近目标图，同时保留 Compatibility 渲染器和质量档位控制。

第三十三轮升级强化驾驶视线中的道路细节：道路增加双色路肩、路面裂缝、反光标和成对弯道导向牌，使长途路线在移动端也有更明确的空间节奏；新增卡车部件统一纳入动漫描边列表。同时修复车库升级提示、交通碰撞反馈和主循环场景更新的缩进问题，避免这些逻辑在 Godot 解析或运行时失效。

第三十四轮升级进行长途运行稳定性整理：修复加油站提示分支的缩进，避免流式道路生物群系细节在左右道路边缘重复生成，减少区段节点数量；相机新增持久化注视目标并平滑插值，驾驶舱与第三人称视角在转弯、碰撞震动和高速 FOV 变化时更稳定。第四轮同时完成主循环、交通、加油和流式道路的静态结构检查。

第三十五轮升级增强长途交通可读性：交通车辆在红灯或低速减速时会提高尾灯发光强度，昼夜系统仍会统一调节车灯亮度；流式道路增加连续车道虚线和两侧琥珀色边缘反光标，使弯道、雪山低能见度和夜间路段更容易辨认。新增节点保持低面数，并完成交通灯数组、道路标记和缩进结构静态检查。
