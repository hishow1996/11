# Runtime Art Pack

These lightweight SVG assets are the runtime-ready art layer for the Godot Compatibility renderer. They are intentionally separate from the 2560×1440 concept atlases in `art/`: roads, particles, liveries and HUD icons can be loaded directly by the game, scaled without blur, and replaced later by authored textures without changing gameplay code.

The generated art remains a visual target/reference; this folder contains the missing production-facing, reusable assets.
