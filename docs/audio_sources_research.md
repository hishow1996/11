# Online Audio Sources Research

## Findings

- OpenGameArt CC0 Sound Effects: https://opengameart.org/content/cc0-sound-effects
  - Page states sound effects with attribution not required.
- Kenney Audio category: https://kenney.nl/assets/category:Audio
  - Official Kenney audio assets page; downloads are available through the Kenney asset ecosystem.
- Kenney UI Audio Godot package: https://github.com/Calinou/kenney-ui-audio
  - README describes 50 UI sound effects, WAV conversion for Godot compatibility, and CC0 1.0 Universal licensing.
- OpenGameArt commercial-use audio collection: https://opengameart.org/content/audio-commercial-use-ok
- OpenGameArt library of game sounds: https://opengameart.org/content/library-of-game-sounds
- OpenGameArt ambient sounds: https://opengameart.org/content/ambient-sounds
- OpenGameArt rain and thunders: https://opengameart.org/content/rain-and-thunders
- Pixabay car game sound effects search: https://pixabay.com/sound-effects/search/car%20game/
- Mixkit car sound effects: https://mixkit.co/free-sound-effects/car/

## Caution

Before importing any third-party file, verify the exact asset page license and retain attribution/credit files when required. Current project already contains a Kenney UI audio folder and its UI click asset. This research did not automatically download third-party files.
